# Telematic Network Diagnostics v0.8.0

Public prerelease · 公开预发布版

## English

- Diagnose each node's public connection to the HUB. Local-device probes,
  phone joining and performer-pair estimates have been removed.
- Switch between geographic and topology views. The geographic view fits
  known nodes and the HUB with a compact, locally bundled continental outline.
  Node colors link map marks, paths and table rows without moving coordinates.
  Only “This node” stays labeled; hover/focus previews the matching details,
  and click pins them. Pond, Sand, Stage and Brutal themes are supported.
- Updated HUBs can supply approximate public-IP locations and accept a
  session-only correction for the local node. The HUB's own position requires
  deployment coordinates. Older HUBs continue to support measurements and
  topology; missing location metadata stays unknown. The HUB deploys separately.
- Stale readings are hidden. A lost HUB or observation connection leaves
  unconfirmed nodes gray rather than displaying old values as live data.
- This is a schemaVersion 2 project for PNDS App v1.6.2 or a compatible Host,
  using exact shared libraries: Express 5.3.0, Socket.IO 4.8.4 and
  Socket.IO Client 4.8.4. No map framework or new runtime dependency is added.

RTT is informational. Jitter, loss, reconnects and connectivity describe public
network stability; these measurements do not determine audio playability.
IP coordinates estimate a network exit and do not establish a district or venue.

Download **`telematic-network-diagnostics-v0.8.0.pnds`** from the release assets
and open it in PNDS App. Source archives are development checkouts.

## 中文

- 仅诊断各节点到公网 HUB 的连接，移除局域网设备探测、手机加入和演奏者对推导。
- 保留地理／拓扑切换。地图按已知节点与 HUB 自动取景，底图只有随包携带的
  简化大陆轮廓。节点色贯穿圆点、连线和表格，不偏移地理坐标。地图只常显
  “本站”；悬停或聚焦联动下方详情，点击可固定。适配四套 App 主题。
- 新版 HUB 可提供公网 IP 的大致位置，并接受本站在本次会话中的手动校正。
  中继自身位置须由部署配置提供。旧 HUB 继续支持测量和拓扑，缺少位置数据
  时显示未知。HUB 需要单独部署，发布工具不会自动升级中继。
- 隐藏过期读数；HUB 或观察连接中断时显示灰色待确认，不把旧值当作实时结果。
- 工程采用 schemaVersion 2，需 PNDS App v1.6.2 或具备相同共享库能力的 Host。
  固定共享库为 Express 5.3.0、Socket.IO 4.8.4 和 Socket.IO Client 4.8.4；
  没有新增地图框架或运行依赖。

RTT 仅作为数据展示；抖动、丢包、重连与连接状态用于判断公网链路稳定性，
不据此判断音频能否演奏。IP 位置估计的是网络出口，不保证区县或场地精度。

从发布附件下载 **`telematic-network-diagnostics-v0.8.0.pnds`**，在 PNDS App 中
打开即可。源码压缩包用于开发，不是可直接安装的工程包。
